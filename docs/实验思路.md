# 实验思路

## 1. 当前实验主线

当前主线采用 `draw_hyperparameters_LHS_v7.py` 生成群体物理超参数，再基于这些超参数生成双探测器时域数据，最后在 `timeflow_v1_a` 中训练条件后验模型。

整体目标是：

- 从 `H1 + L1` 双通道时域数据中直接学习群体物理超参数的后验分布；
- 重点关注双黑洞并合产生的随机引力波背景；
- 用 `CNN + Normalizing Flow` 建立 `p(theta | x)` 的近似后验模型。

这里：

- `x` 表示双探测器时域输入；
- `theta` 表示待推断的群体物理超参数。

## 2. 当前物理超参数设定

### 2.1 参数顺序

`draw_hyperparameters_LHS_v7.py` 中的原始标签顺序为：

```text
[alpha_z, beta_z, zp, alpha_m, m_max, delta_m, m_min, lambda_peak, mu_m, sigma_m, beta_q]
```

在 `timeflow_v1_a/dataset.py` 中，对应到训练标签时使用的原始索引顺序为：

```text
[zp, alpha_z, beta_z, alpha_m, m_max, delta_m, m_min, lambda_peak, mu_m, sigma_m, beta_q]
```

两者只是排列顺序不同，物理量本身是一致的。

### 2.2 当前使用的采样模式

`draw_hyperparameters_LHS_v7.py` 当前设置为：

```python
USE_V4_ALPHAZ_WITH_RANDOM_BETAZ = False
```

因此当前主线不是使用 `v4` 的线性 `alpha_z(zp)` 关系，而是采用独立采样模式：

- `zp` 独立采样；
- `alpha_z` 独立采样；
- `beta_z` 独立采样；
- 其余质量分布相关参数也独立采样。

### 2.3 当前各物理超参数含义与范围

#### 红移模型参数

| 参数 | 含义 | 当前范围 |
|---|---|---|
| `zp` | 红移分布的特征峰值位置参数，决定事件分布主要集中在什么红移附近 | `[0.85, 2.85]` |
| `alpha_z` | 低红移端上升斜率，控制低红移处事件率随红移增加的快慢 | `[1.0, 3.0]` |
| `beta_z` | 高红移端下降斜率，控制高红移处事件率衰减的快慢 | `[1.0, 5.0]` |

#### 双黑洞质量模型参数

| 参数 | 含义 | 当前范围 |
|---|---|---|
| `alpha_m` | 主黑洞质量分布的幂律斜率 | `[-3.0, 7.0]` |
| `delta_m` | 低质量端平滑截断宽度 | `[0.0, 10.0]` |
| `mu_m` | 高斯峰位置参数 | `[25.0, 50.0]` |
| `sigma_m` | 高斯峰宽度参数 | `[0.01, 5.0]` |
| `beta_q` | 质量比 `q` 分布的幂律指数 | `[-5.0, 5.0]` |

#### 固定参数

| 参数 | 含义 | 当前取值 |
|---|---|---|
| `m_max` | 主黑洞质量上限 | `100.0` |
| `m_min` | 主黑洞质量下限 | `2.0` |
| `lambda_peak` | 高斯峰混合权重 | `0.04` |

### 2.4 当前真正参与训练的参数

`timeflow_v1_a/dataset.py` 当前的 `SELECTED_PARAMETERS` 为：

```python
["zp", "alpha_z", "beta_z", "alpha_m", "delta_m", "mu_m", "sigma_m", "beta_q"]
```

因此当前训练任务是一个 **8 维后验推断任务**，固定参数：

- `m_max`
- `m_min`
- `lambda_peak`

不进入训练标签。

## 3. 数据生成思路

### 3.1 总体流程

当前实验链路可以概括为：

1. 先利用 LHS 在给定范围内采样大量群体物理超参数；
2. 对每组超参数，建立对应的双黑洞群体模型；
3. 在给定时长的 frame 内采样大量双黑洞事件参数；
4. 对每个事件生成波形，并投影到 `H1`、`L1` 两个探测器；
5. 将同一 frame 内的所有事件信号叠加，得到双探测器时域序列；
6. 将处理后的 `H1/L1` 时域数据与对应群体标签一起保存为训练样本。

### 3.2 数据形式

在进入 `timeflow_v1_a` 训练前，单个样本最终表现为：

- 一条 `H1` 时域序列；
- 一条 `L1` 时域序列；
- 一组与该样本对应的群体物理超参数标签。

因此模型输入本质上是：

```text
2 通道时域序列 -> 8 维群体超参数后验
```

### 3.3 当前样本构造特点

当前样本并不是单个 resolved event，而是：

- 在固定时长 frame 内，
- 由多次双黑洞并合事件叠加形成的时域信号段。

因此这项任务不是传统单事件参数估计，而是：

- **从随机引力波背景样本中恢复群体超参数。**

## 4. 模型训练思路

### 4.1 模型目标

训练目标是学习条件后验：

```text
p(theta | x)
```

其中：

- `x` 是双探测器时域输入；
- `theta` 是 8 维群体超参数。

### 4.2 模型结构

当前采用两部分结构：

1. 用一维卷积网络从 `H1 + L1` 时域数据中提取上下文特征；
2. 用条件 Normalizing Flow 学习超参数的后验分布。

这一结构的优势在于：

- CNN 负责从原始时域数据中提取有效统计特征；
- Flow 不只给点估计，而是直接输出完整后验分布。

### 4.3 当前训练超参数

`timeflow_v1_a/train_flow.py` 当前主要训练配置为：

| 参数 | 当前值 |
|---|---:|
| `BATCH_SIZE` | `64` |
| `EPOCHS` | `20` |
| `LEARNING_RATE` | `1e-4` |
| `WEIGHT_DECAY` | `1e-4` |
| `VAL_FRACTION` | `0.1` |
| `TEST_FRACTION` | `0.1` |
| `NUM_WORKERS` | `0` |
| `CONTEXT_DIM` | `256` |
| `FLOW_LAYERS` | `8` |
| `FLOW_HIDDEN` | `256` |
| `FLOW_BINS` | `8` |
| `FLOW_TAIL_BOUND` | `3.0` |

### 4.4 当前标准化方式

#### 特征标准化

对输入特征：

1. 先将时域应变乘以 `1e23`；
2. 对每个样本的每个通道单独去均值；
3. 再用训练集统计得到的 `feature_mean/std` 做通道级标准化。

#### 标签标准化

对标签：

1. 先从完整标签中抽取当前 8 个训练参数；
2. 再用训练集统计得到的 `label_mean/std` 做标准化。

因此当前训练、验证、测试三部分都统一使用训练集统计量，不存在明显的数据泄漏问题。

## 5. 实验评估思路

当前主要从以下几个角度评估模型：

- 测试集平均 `NLL`；
- 各参数的 `MAE`；
- `68% / 95%` 覆盖率；
- `68% / 95%` 置信区间宽度；
- 单样本联合后验分布图；
- 必要时结合 MCMC 对单样本后验进行进一步检查。

核心关注点不是单一误差指标，而是：

- 后验是否足够窄；
- 后验是否覆盖真值；
- 后验是否校准合理；
- 多参数联合分布是否具有物理可解释性。

## 6. 当前实验重点

基于当前 `v7` 设定，当前实验的重点可以概括为：

1. 研究 8 维群体超参数在时域 SGWB 数据中的可识别性；
2. 比较不同参数的恢复难度；
3. 分析单 frame 与多 frame 条件下后验分布的变化；
4. 评估深度学习方法相对于传统二阶统计框架的潜在优势，尤其是对更高阶统计信息的利用能力。

## 7. 当前文档对应的主线结论

当前这条实验主线的关键特征是：

- 物理超参数来源于 `draw_hyperparameters_LHS_v7.py`；
- 当前实际采用的是 `USE_V4_ALPHAZ_WITH_RANDOM_BETAZ = False` 的独立采样模式；
- 当前训练目标是 8 维群体超参数后验；
- 当前输入是 `H1 + L1` 双通道时域数据；
- 当前模型主线是 `CNN + Conditional Normalizing Flow`；
- 当前评估重点是后验质量，而不仅仅是点估计误差。
