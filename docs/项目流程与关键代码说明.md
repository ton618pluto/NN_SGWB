# LIGO_SGWB 项目流程与关键代码说明

## 1. 项目目标

本项目研究如何从 H1、L1 探测器的双通道时域数据中，使用 `CNN + Normalizing Flow` 推断产生 CBC-SGWB 的群体物理参数后验分布。

当前模型预测以下 `8` 个参数：

- `zp`
- `alpha_z`
- `beta_z`
- `alpha_m`
- `delta_m`
- `mu_m`
- `sigma_m`
- `beta_q`

## 2. 整体流程

项目的数据与模型流程为：

```text
CBC 群体物理参数
        ↓
采样群体中的 CBC 事件参数
        ↓
生成 H1/L1 探测器响应并叠加为 CBC-SGWB 信号
        ↓
加入由固定 ASD 生成的探测器噪声
        ↓
将 GWF 时域数据转换为模型使用的 NPY 数据
        ↓
使用双通道 CNN 提取 H1/L1 时域特征
        ↓
使用条件 Normalizing Flow 学习 8 个物理参数的联合后验
        ↓
使用测试集和 Cobaya MCMC 绘制、分析后验分布
```

## 3. 数据集构建

### 3.1 CBC-SGWB 信号

首先从群体分布超参数出发，采样一组 CBC 事件参数；然后生成每个事件在 H1 和 L1 中的响应，并将同一时间段内的 CBC 信号叠加，得到对应群体参数下的一段 CBC-SGWB realization。

不同的 CBC 事件采样可以产生不同的信号 realization。即使这些信号对应同一组群体物理参数，其具体事件数量、质量、红移、并合时间和时域波形也可以不同。

### 3.2 探测器噪声

噪声由指定的探测器 ASD 生成。当前主要结果使用原 O4 噪声幅度的 `1/100`：

```text
输入数据 = Signal + 0.01 × Original O4 Noise
```

这里的 `1/100` 指噪声时域幅度缩放，不表示更换了 ASD 的谱形。

### 3.3 同一信号随机配对两段噪声

训练集对同一个 SGWB 信号随机配对 `2` 段独立噪声：

```text
X_i,1 = S_i + N_i,1
X_i,2 = S_i + N_i,2
```

两个样本共享同一组物理参数标签，但使用不同的噪声 realization。该策略用于减少标签与某一段具体噪声形成偶然对应关系的可能性，促使模型利用不同样本中共同存在的信号信息。

当前数据集包含约 `30 万` 组信号，每组信号配对 `2` 段噪声，最终形成约 `60 万` 个 H1/L1 双通道样本，整体存储规模约为 `10 TB`。

## 4. 模型与训练

模型输入是标准化后的 H1/L1 双通道时域序列：

```text
input shape = [batch, 2, time]
```

CNN 编码器负责从长时域序列中提取条件特征，Normalizing Flow 在该条件特征下学习 `8` 个群体物理参数的联合后验分布。训练目标是最大化真实参数在条件后验中的概率，代码中等价为最小化负对数概率：

```text
loss = -log p(theta | H1, L1)
```

训练得到的 checkpoint 同时保存模型权重、标签标准化统计量和输入特征标准化统计量；测试时必须使用与 checkpoint 对应的数据版本及标准化配置。

## 5. 测试设计与当前结果

### 5.1 原测试样本

原测试使用未参与训练的 `Signal + Noise` 样本，检查模型能否恢复对应的真实群体物理参数。

### 5.2 独立的 Signal* + Noise* 测试

项目还进行了更严格的独立测试：

- `Signal*`：在同一组群体物理参数下重新采样 CBC 事件并生成的不同 CBC-SGWB realization；
- `Noise*`：由同一 ASD 重新生成的不同随机噪声 realization；
- `Signal* + Noise*`：信号和噪声的具体 realization 均不同于原样本，但目标群体物理参数保持不变。

模型在 `Signal* + Noise*` 上仍能准确预测 `8` 个物理参数。这说明在固定 ASD 和 `1/100` 原 O4 噪声强度下，模型能够泛化到未见过的信号 realization 与噪声 realization，而不是只记忆某一段固定信号或固定噪声。

### 5.3 单帧与多帧后验

单帧输入用于观察一段 H1/L1 数据能够提供的参数信息；多帧联合推断用于综合多段独立数据提供的共同证据，通常可以得到更稳定、更集中的后验分布。

## 6. 当前结论的适用范围

当前结果支持：

- 在固定 ASD 条件下进行 CBC-SGWB 群体参数推断；
- 在原 O4 噪声幅度缩放至 `1/100` 的条件下准确预测 `8` 个参数；
- 泛化到同一群体参数下不同的 CBC-SGWB 信号 realization；
- 泛化到同一 ASD 下不同的随机噪声 realization；
- 在信号和噪声 realization 同时变化的 `Signal* + Noise*` 测试中保持准确预测。

不同 ASD 会改变噪声的频率分布和输入统计特征，属于噪声域偏移或跨域泛化问题。跨 ASD 泛化不是当前同域实验成立的必要条件，可作为后续独立研究方向。

## 7. 关键代码文件

下面只列出项目主流程中较关键的文件，不包含全部辅助脚本。

### 7.1 群体参数与信号生成

- `scripts/draw_hyperparameters_LHS_v7.py`：使用拉丁超立方采样生成 `v100` 数据集的 `30 万` 组群体物理参数，其中包含 `8` 个变化参数和 `3` 个固定参数。
- `scripts/draw_hyperparameters_fixed_one_test.py`：生成固定群体物理参数的独立测试配置，用于构建同参数下的新信号 realization。
- `scripts/generate_pure_cbc_frames_sampling5_silent_no_double_redshift.py`：根据采样的 CBC 事件参数生成训练用 H1/L1 纯 CBC-SGWB 信号帧。
- `scripts/generate_pure_cbc_frames_sampling5_silent_no_double_redshift_test.py`：生成测试用 H1/L1 CBC-SGWB 信号帧。

### 7.2 噪声生成与信号叠加

- `scripts/generate_pure_noise_frames_seed.py`：按照指定噪声谱和随机种子生成可复现的探测器噪声 GWF 文件。
- `scripts/superimposed_friendly_random_two_noise_to_npy.py`：将每组训练信号随机配对两段噪声，并直接生成带标签的 H1/L1 NPY 训练样本。
- `scripts/superimposed_friendly_test_random_noise.py`：为独立测试信号配对新的随机噪声并生成测试用叠加 GWF 文件。
- `scripts/processData_test_superimposed.py`：将测试集的 `Signal + Noise` GWF 文件切分并转换为模型可读取的 NPY 文件。

### 7.3 TimeFlow 数据、模型与训练

- `scripts/timeflow_v1_a/dataset.py`：匹配 H1/L1 样本、选择 8 个标签参数并完成输入与标签标准化。
- `scripts/timeflow_v1_a/model.py`：定义双通道一维 CNN 编码器和条件 Normalizing Flow 模型。
- `scripts/timeflow_v1_a/train_flow.py`：负责数据集划分、模型训练、验证、checkpoint 和训练配置保存。
- `scripts/timeflow_v1_a/train_flow_by_pop.py`：按 population 组织训练/验证/测试划分，减少同一群体样本跨集合造成的信息泄漏风险。

### 7.4 后验预测与评估

- `scripts/timeflow_v1_a/evaluate_test_set.py`：批量评估测试集的参数误差、可信区间宽度和覆盖情况。
- `scripts/timeflow_v1_a/predict_test_sample_cobaya_mcmc_single_frame.py`：对一帧 `Signal + Noise` 数据运行 Flow 后验和 Cobaya MCMC，并绘制 corner 图。
- `scripts/timeflow_v1_a/predict_test_sample_cobaya_mcmc_multi_frame.py`：联合多帧数据计算后验，用于观察多段独立证据的累积效果。
- `scripts/timeflow_v1_a/show_test_sample_hyperparameters.py`：读取测试样本标签并核对后验图中的真实参数值和数据文件来源。
- `scripts/timeflow_v1_a/evaluate_joint_coverage_2d.py`：评估二维联合可信区域对真实参数组合的覆盖情况。
- `scripts/timeflow_v1_a/evaluate_mahalanobis.py`：使用参数空间中的马氏距离分析联合后验与真实值的偏离程度。

### 7.5 数据核对工具

- `scripts/check_superimposed_gwf_vs_processed_npy.py`：核对叠加后的 GWF 数据与预处理 NPY 数据是否一致。
- `scripts/check_superimposed_by_pop_labels.py`：检查同一 population 下不同噪声配对样本是否保持相同物理参数标签。
- `scripts/compare_processed_data_superimposed_features.py`：比较不同叠加数据版本的输入统计特征，辅助排查尺度或预处理差异。
