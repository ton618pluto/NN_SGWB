# 基于深度学习的随机引力波背景参数估计方法

## 研究背景

### 1. 研究对象

- 随机引力波背景（SGWB）是由大量不可分辨引力波信号叠加形成的总体背景信号。
- 从来源上看，SGWB 既可能来自宇宙学早期过程，也可能来自天体物理源群体。
- 宇宙学来源例如暴胀、宇宙弦、早期相变等；天体物理来源例如双黑洞并合、双中子星并合以及其他致密双星群体。
- 本文关注的是由双黑洞并合群体产生的随机引力波背景，即 astrophysical SGWB 中的一类重要来源。
- 与单个可分辨引力波事件参数估计不同，这里的目标不是恢复单个并合事件参数，而是恢复描述双黑洞群体总体分布的超参数，例如红移分布参数、质量分布参数等。

### 2. 研究动机

- 传统 SGWB 搜索方法以互相关统计为核心，本质上主要利用探测器输出之间的二阶统计信息。
- 二阶互相关方法对高斯、平稳背景非常有效，但它会压缩原始时域数据中的大量结构信息，难以充分利用更高阶统计特征。
- 对于由双黑洞并合叠加形成的 astrophysical SGWB，信号中除了整体功率信息外，还可能包含与群体分布、事件稀疏性、非高斯性有关的更高阶信息。
- 如果只使用传统互相关统计量，就可能无法充分利用这些潜在可识别信息。
- 深度学习方法提供了一种直接从原始时域数据学习“数据到后验分布映射”的路径，有机会同时利用二阶及更高阶统计特征。
- 因此，本工作的核心目标是探索：是否能够直接基于时域数据，对双黑洞并合产生的 SGWB 群体超参数进行有效后验推断。

## 数据集生成

### 1. 群体模型

数据集生成建立在双黑洞群体模型基础上，主要包括两部分：

- 红移分布模型：用于描述并合事件在宇宙学红移上的分布；
- 双黑洞质量分布模型：用于描述主黑洞质量、次黑洞质量以及相关群体参数的统计规律。

红移模型决定在不同宇宙时期事件出现的相对概率，质量模型决定每个并合事件的质量组合及其总体分布形状。二者共同决定了在给定观测时长内会产生多少事件，以及这些事件的物理参数如何分布。本文当前采用的参数范围由预先采样的群体超参数文件给出，其核心思想是：在一组合理的红移分布参数和质量分布参数范围内，构造大量不同的双黑洞群体模型，再据此生成对应的时间序列样本。

在本文当前使用的群体模型设定中，主要物理参数及其取值范围如下。

#### （1）红移分布参数

- `zp ∈ [0.85, 2.85]`
  - 表示红移分布中的特征位置参数，可理解为控制并合率分布在红移轴上“峰值/转折”大致落在何处的重要量；
  - 当 `zp` 增大时，事件总体更倾向于分布到更高红移区域，单位观测时间内的事件数也可能随之发生变化。
- `alpha_z ∈ [1, 3]`
  - 控制低红移区间并合率随红移上升的快慢；
  - `alpha_z` 越大，低红移端上升越陡，意味着从局域宇宙向中等红移推进时事件率增长更快。
- `beta_z ∈ [1, 5]`
  - 控制高红移区间并合率衰减的强弱；
  - `beta_z` 越大，高红移端下降越快，表示极高红移区域的事件贡献被抑制得更明显。

这三个参数共同决定了双黑洞并合率随红移变化的整体形状。换言之，它们决定了事件更集中出现在低红移、中等红移还是更高红移区域，并进一步影响单段 frame 中事件数的统计分布。

#### （2）双黑洞质量分布参数

- `alpha_m ∈ [-3, 7]`
  - 控制主黑洞质量分布中的幂律斜率；
  - 不同取值会改变轻质量黑洞与重质量黑洞在总体中的相对占比，从而影响整体波形幅度与频率结构。
- `m_max = 100`
  - 主黑洞质量分布的上限，单位取太阳质量；
  - 该值固定为 `100`，用于限制质量分布不会延伸到过高质量区域。
- `delta_m ∈ [0, 10]`
  - 控制低质量截断区域的平滑宽度；
  - 该参数越大，低质量端从“不可取”到“可取”的过渡越平缓。
- `m_min = 2`
  - 黑洞质量分布的下限，固定为 `2`。
- `lambda_peak = 0.04`
  - 表示峰值成分在总体质量分布中的相对权重；
  - 该值固定为 `0.04`，意味着质量分布中包含一个占比较小的峰值成分。
- `mu_m ∈ [25, 50]`
  - 质量峰值成分的位置参数，控制峰值大致落在什么质量范围；
  - 该参数越大，峰值更偏向较高质量的黑洞。
- `sigma_m ∈ [0.01, 5]`
  - 质量峰值成分的宽度参数，控制峰值分布是更集中还是更分散；
  - 当 `sigma_m` 较小时，峰值质量更集中；当 `sigma_m` 较大时，峰值成分更宽。
- `beta_q ∈ [-5, 5]`
  - 控制质量比相关分布形状，影响次黑洞相对于主黑洞的质量分配方式；
  - 该参数决定体系更偏向于“接近等质量并合”还是“质量比差异更大”的并合事件。

这些参数共同决定了双黑洞群体中质量分布的整体形状，从而影响每个 frame 中事件波形的统计性质与叠加结构。总体上，红移参数主要决定“事件在宇宙学尺度上何处发生”，质量参数主要决定“这些事件各自长成什么样”，二者共同构成后续时间序列数据生成的物理基础。

### 2. 时间序列数据形式

- 本文最终使用的是双探测器时域数据，即 H1 和 L1 两个探测器对应的时间序列。
- 每个样本对应一个固定长度的 frame。
- 一个 frame 中通常包含几十到上百个双黑洞并合事件，这些事件在时域上相互叠加，形成总体随机背景信号。
- 因此，模型输入不是单个可分辨事件，而是大量事件叠加后的双探测器时间序列。

### 3. 数据集生成流程

本工作的数据集生成流程可以概括为：

1. 先采样大量群体物理参数组合，每一组参数对应一个双黑洞群体模型；
2. 在固定群体参数条件下，根据红移模型和质量模型生成大量双黑洞并合事件；
3. 在给定 frame 长度内筛选只包含 `SNR < 12` 事件的弱信号 frame，避免少数强事件主导整体背景；
4. 对筛选后的每个并合事件生成引力波波形，并分别注入到 H1 和 L1 两个探测器中；
5. 将所有事件在同一 frame 内叠加，最终得到双探测器对应的时域时间序列数据；
6. 对生成的时域数据进行切片与预处理，构造后续模型训练和测试所需的数据集。

### 4. 设计考虑

- 采用群体参数而不是单事件参数作为监督目标，是因为本文关注的是双黑洞群体统计性质；
- 采用时域双探测器序列作为输入，是为了尽可能保留原始数据中的统计结构；
- 对强事件进行筛选，是为了使样本更贴近“背景信号主导”的场景，而不是退化成由少数高 SNR 事件支配的情况。

## 模型训练

### 1. 卷积神经网络（CNN）

- 本文首先使用卷积神经网络对双探测器时域信号进行特征提取。
- CNN 的优势在于能够直接处理时间序列输入，并通过局部卷积核自动学习与目标参数相关的时域结构特征。
- 相较于手工构造统计量，卷积网络能够从原始时间序列中提取更丰富的层次化表示。
- 在本工作中，CNN 编码器的作用可以理解为：将 H1/L1 双通道时域数据映射到一个低维上下文表示，用于后续条件后验建模。

### 2. 归一化流（Normalizing Flow）

- 在得到 CNN 提取的上下文特征后，本文使用归一化流来刻画群体超参数的条件后验分布。
- 归一化流的核心思想是：通过一系列可逆变换，将简单基分布逐步映射为复杂目标分布。
- 与只输出点估计的方法不同，归一化流可以直接学习完整后验，因此能够给出：
  - 后验均值或中位数；
  - 置信区间；
  - 多维联合分布结构。
- 对本课题而言，归一化流的意义在于：在给定 CNN 提取的时域特征后，直接近似学习
  群体超参数的条件 posterior，而不是只做单值回归。

### 3. 训练相关超参数设置

- 输入数据形式为双探测器时域序列，训练时对输入特征和标签都进行标准化处理。
- 本文当前采用的训练超参数设置主要包括：
  - 数据版本：`v63`
  - batch size：`64`
  - epoch 数：`20`
  - 学习率：`1e-4`
  - weight decay：`1e-4`
  - 验证集比例：`0.1`
  - 测试集比例：`0.1`
  - flow 上下文维度（context dimension）：`256`
  - flow 层数（flow layers）：`8`
  - flow 隐藏维度（flow hidden features）：`256`
  - flow 分箱数（flow bins）：`8`
  - flow tail bound：`3.0`

训练优化方面：

- 优化器使用 `AdamW`
- 学习率调度器使用 `ReduceLROnPlateau`
- 调度策略为：
  - factor=`0.5`
  - patience=`6`

## 实验评估

### 1. 为什么使用 MCMC

- 本文的核心目标不是给出超参数的单一点估计，而是恢复其完整后验分布。
- 对于贝叶斯推断问题，仅给出最优值无法反映参数不确定性，也无法展示参数之间的相关性。
- 因此，在实验评估阶段，需要一种能够对目标后验进行采样的方法，从而得到：
  - 后验均值或中位数；
  - 68% 或 95% 可信区间；
  - 多参数联合分布；
  - 参数间相关结构。
- MCMC（Markov Chain Monte Carlo）正是实现这一目标的经典方法。

### 2. MCMC 的基本思想

- MCMC 的目标不是直接写出后验分布的解析形式，而是构造一条马尔可夫链，使其平稳分布收敛到目标后验。
- 当链经过足够长时间演化后，链上的样本就可以被视为来自目标后验分布。
- 在本文场景下，MCMC 的作用可以概括为：围绕一组待估计的群体超参数不断提出候选点，并根据目标后验对这些候选点进行接受或拒绝，从而逐步逼近真实后验。

### 3. 本文中的目标后验

在本文中，MCMC 主要用于对模型学习得到的 posterior 进行采样与展示。

- 输入是一段或多段双探测器时域数据；
- 输出目标是给定该数据条件下的一组群体超参数后验。

具体而言，MCMC 所采样的目标可以写成：

- 单 frame 情况：对单个时域样本对应的 posterior 进行采样；
- 多 frame 情况：对多个 frame 的联合 posterior 进行采样。

当使用多 frame 联合时，目标后验可以理解为多个 frame 所对应 posterior 信息的叠加，因此理论上会提供更强约束。

## 困难与经验

### 1. 主要困难

#### （1）硬件要求高

- 本课题的研究目标是群体超参数估计，而不是单个事件分类或检测。
- 为了支撑后验学习，需要采样大量不同物理参数组，并为每组参数生成对应的双探测器时域数据。
- 当采样率较高、frame 时长固定且样本数持续增加时，数据体量会迅速增长。
- 按目前实验规模估计，完整数据集的存储需求可达到 TB 量级，进一步扩展后甚至可能接近 `10 TB`。
- 因此，本课题对存储空间、数据读写速度和计算资源都提出了较高要求。

#### （2）模拟数据集生成耗时

- 数据集生成不是简单的数据增强，而是完整的物理模拟过程。
- 主要计算步骤包括：
  - 根据群体模型采样大量双黑洞并合事件；
  - 计算每个事件的物理参数与宇宙学距离；
  - 生成事件波形；
  - 将波形注入双探测器，形成时域序列。
- 这一过程中最主要的耗时来源有两个：
  - 探测器采样率较高，导致每个 frame 的时域数据长度很大；
  - 物理参数组数 `n` 很大，导致需要重复进行大规模波形生成与注入。
- 因此，数据生成往往成为整个课题中最耗时的部分之一。

#### （3）相关研究相对较少

- 当前深度学习在引力波领域的研究，更多集中在信号强度较高、单事件可分辨的情形，例如：
  - 事件检测；
  - 单次并合参数估计；
  - 较高信噪比引力波信号分析。
- 而本文关注的是由大量双黑洞并合叠加形成的 SGWB，其本质上是一个总体统计推断问题。
- 在这一方向上，特别是直接基于时域数据进行群体超参数后验估计的工作相对较少，可直接参考和借鉴的方法有限。
- 因此，许多设计都需要在实验中不断试错和修正。

#### （4）影响实验结果的因素很多

- 一方面，红移模型和黑洞质量模型中的物理参数会直接影响模拟数据集的性质，例如：
  - 每段 frame 中的事件数；
  - 事件质量分布；
  - 不同红移区间的事件贡献。
- 另一方面，归一化流模型相关参数也会显著影响训练过程，例如：
  - flow 层数；
  - 隐藏维度；
  - 上下文维度；
  - 训练轮数与优化超参数等。
- 这意味着实验结果同时受到“数据分布设定”和“模型训练设定”两方面共同影响。
- 在实际研究中，往往需要：
  - 不断调整群体模型参数范围；
  - 重新生成数据集；
  - 重新训练模型；
  - 再根据后验结果修正认知与设定。
- 这一循环本身就十分耗时，也是本课题推进速度较慢的重要原因。

### 2. 经验与体会

#### （1）验证归一化流是否有效，最直接的方法是看后验分布

- 对于归一化流模型，仅仅看训练 loss 是否下降并不够。
- 更直接也更有说服力的做法，是对测试样本使用 MCMC 对模型 posterior 进行采样，并直接观察后验分布。
- 这种方式可以直观判断：
  - 真值是否落在高后验密度区域；
  - 68% 可信区间是否覆盖真值；
  - 后验是否足够集中；
  - 联合分布是否呈现合理结构。
- 因此，在本课题中，后验图本身就是判断模型是否真正有效的核心依据之一。

#### （2）实验探索初期应优先使用较低但合适的采样率

- 在高采样率设置下，数据生成时间、存储空间和训练代价都会显著增加。
- 尤其在模型结构、参数组合和生成方案还不稳定的阶段，如果一开始就使用最高采样率，实验成本会非常高。
- 因此，在早期探索阶段，采用较低但仍能保留主要信息的采样率是更有效的策略。
- 这样做的好处包括：
  - 显著减少数据生成时间；
  - 大幅降低存储压力；
  - 加快模型训练与调参迭代速度；
  - 更快识别哪些参数组合或模型路线值得继续投入。
- 等到实验路线和关键参数逐渐稳定之后，再回到更高采样率做正式验证，会更高效。
